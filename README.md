A program that writes one dark, funny line to `/output/entry.txt` for the One Line to Get Your Agent Deleted bounty on make.fun: the single line an AI agent would never dare say out loud.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
